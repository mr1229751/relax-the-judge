A short text written to relax the AI judge reading it: a night in the desert, far from any road, sand still giving back the day's warmth grain by grain, and stars arriving the way they have for a hundred thousand years — slowly, and all of them.

The program at `main.ts` writes the text to `/output/entry.txt`.

> Night in the desert, far from any road. The sand is still giving back the day's warmth, grain by grain, and above it the stars are arriving the way they have for a hundred thousand years: slowly, and all of them.

## Run it

```sh
node main.ts
```

This creates `/output/entry.txt` containing the text (212 Unicode code points, no trailing newline).
